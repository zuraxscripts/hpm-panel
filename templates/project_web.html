Architecture snapshot

Python backend, SocketIO updates, template UI, configurable storage, and controlled updater orchestration.

Core Platform

  • Single entry manager process with dependency bootstrap.
  • API-first Flask app with socket events for live updates.
  • JSON storage with optional encrypted MySQL credentials.
  • Server-path jailing and guarded file operations.
  • Background updater for panel and server binaries.
